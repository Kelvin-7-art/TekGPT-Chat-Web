# 🎬 Media Folder

This folder contains:
- **videos/** - Demo videos (.mp4, .mov)
- **gifs/** - Animated GIFs (.gif)

## Recommended Tools

### For GIFs
- [ScreenToGif](https://www.screentogif.com/) - Free, Windows
- [GIPHY Capture](https://giphy.com/apps/giphycapture) - Mac
- [OBS Studio](https://obsproject.com/) + FFmpeg

### For Videos
- [OBS Studio](https://obsproject.com/) - Free, all platforms
- [QuickTime Player](https://support.apple.com/quicktime) - Mac
- [Windows Game Bar](https://support.microsoft.com/game-bar) - Windows + Win+G

## File Naming Convention

- demo.mp4 - Full demo video
- demo.gif - Quick demo animation
- image-analysis.gif - Image analysis feature
- mobile-view.mp4 - Mobile responsiveness demo
